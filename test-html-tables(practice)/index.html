Task 1: Basic Table Structure

Learn the fundamental structure of HTML tables.

Simple Table Syntax

<table>
  <tr>
    <td>Cell 1</td>
    <td>Cell 2</td>
  </tr>
</table>

Table Elements:

  • <table> - Container for the entire table
  • <tr> - Table row (horizontal line)
  • <td> - Table data (regular cell)
  • <th> - Table header (special header cell)

Example Table:

Name Age City
Alice 28 New York
Bob 32 Los Angeles
Key Concepts:
  • Always use <th> for headers, not <td>
  • Each <tr> creates one complete row
  • Number of <td>/<th> should be consistent
  • Tables should have headers for accessibility

Learning Syntax Summary

📊 Basic Tables

Use <table>, <tr>, <td>, and <th> to create tables.

🏗️ Structure

Use <thead>, <tbody>, <tfoot> for semantic structure.

♿ Accessibility

Use scope attribute and captions for screen reader support.

🎨 Styling

Use CSS to style and make tables responsive.
