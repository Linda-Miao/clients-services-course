Task 1: Basic HTML Animals

Learn about paragraphs and headings with animal descriptions.

This is the first paragraph in our page. It introduces our animals.

The Llama

Our Llama is a big fan of list items. When she spies a patch of them on a web page, she will eat them like sweets, licking her lips as she goes.

The Anaconda

The crafty anaconda likes to slither around the page, traveling rapidly by way of anchors to sneak up on his prey.

Key Concepts:
  • <h3> - Heading level 3 for subheadings
  • <p> - Paragraph element for text content
  • Proper use of semantic HTML

Task 2: Working with Lists

Practice creating unordered and ordered lists.

My Favorite Vegetables (Unordered List)

  • Cucumber
  • Broccoli
  • Asparagus
  • Pepper

Directions (Ordered List)

  1. First knock on the door
  2. When prompted, say the magic word
  3. Wait for at least 5 seconds
  4. Turn the handle and push
Key Concepts:
  • <ul> - Unordered list (bullet points)
  • <ol> - Ordered list (numbered)
  • <li> - List item

Task 3: Animal Descriptions

Practice organizing content with proper headings and paragraphs.

Llama

Tall, woolly quadruped, pointy ears. Sometimes rideable, but grumpy and spits a lot. Big fan of list items.

Anaconda

A very large constrictor snake; travels rapidly by way of anchors to sneak up on his prey.

Hippopotamus

His description is bottomless.

Key Concepts:
  • Consistent use of heading hierarchy
  • Clear paragraph structure
  • Semantic HTML for readability

Task 4: Emphasis and Importance

Learn how to emphasize text using <strong> and <em>.

There are two things I care about — music and friends. Someday I might be able to get my friends interested in each other, and my music!

Key Concepts:
  • <strong> - Indicates strong importance (bold)
  • <em> - Indicates emphasis (italic)
  • Semantic meaning vs. visual styling

Learning Syntax Summary

Headings

Use <h1> through <h6> to structure the content hierarchically.

Paragraphs

Use <p> to wrap blocks of text content.

Lists

Use <ul> for unordered and <ol> for ordered lists with <li> items.

Emphasis

Use <strong> and <em> to add semantic meaning to text.
