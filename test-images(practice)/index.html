Task 1: Basic Image Tags

Learn the fundamentals of embedding images in HTML.

Simple Image Tag

<img src="image.jpg" alt="Description of image">

Image with Dimensions

<img src="image.jpg" alt="Description" width="400" height="300">

Key Attributes:

  • src - Source path to the image (required)
  • alt - Alternative text for accessibility (required)
  • width - Width in pixels (optional)
  • height - Height in pixels (optional)
  • title - Tooltip text on hover

Image Formats:

  • JPG/JPEG - Best for photographs
  • PNG - Best for graphics with transparency
  • GIF - Good for animations
  • WebP - Modern format with better compression
  • SVG - Scalable vector graphics
Accessibility Tips:
  • Always include descriptive alt text
  • Alt text should be concise but informative
  • For decorative images, use empty alt: alt=""
  • Include relevant details users need to understand

Task 2: Image Paths and Sources

Understand different ways to reference image files.

Relative Path (Same Folder)

<img src="image.jpg" alt="Image">

For images in the same directory as the HTML file.

Relative Path (Subfolder)

<img src="images/image.jpg" alt="Image">

For images in a subfolder named "images".

Relative Path (Parent Folder)

<img src="../image.jpg" alt="Image">

Use ../ to go up one directory level.

Absolute Path (Full URL)

<img src="https://example.com/image.jpg" alt="Image">

For images hosted on external servers.

Path Tips:
  • Use relative paths for local files (easier to move)
  • Use absolute URLs only for external images
  • Organize images in a dedicated folder
  • Use consistent naming conventions (lowercase, no spaces)

Task 3: Responsive and Optimized Images

Learn best practices for responsive and performance-optimized images.

Max-Width for Responsive Images

<img src="image.jpg" alt="Image" style="max-width: 100%; height: auto;">

Image Optimization Tips:

  • Reduce file size using compression tools
  • Use appropriate format for image type
  • Provide multiple sizes for different devices
  • Lazy loading for images below the fold
  • Use CDN for faster delivery
Performance Best Practices:
  • Optimize images before uploading
  • Use modern formats like WebP when possible
  • Implement lazy loading for below-the-fold images
  • Provide alt text for all images
  • Test on different screen sizes

Task 4: Using Figures and Captions

Learn semantic HTML for images with captions using <figure> and <figcaption>.

Figure with Caption

<figure>
  <img src="image.jpg" alt="A colorful butterfly">
  <figcaption>A monarch butterfly resting on a flower.</figcaption>
</figure>

When to Use Figure:

  • Images referenced from the main text
  • Images with explanatory captions
  • Illustrations, diagrams, or charts
  • Photos with important context
📝 Semantic HTML Benefits:
  • Improves accessibility for screen readers
  • Provides semantic meaning to content
  • Better SEO for images
  • Makes code more maintainable
  • Helps with styling consistency
