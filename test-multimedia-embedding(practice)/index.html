Task 1: Working with Images

Learn how to embed and describe images using the <img> tag.

Image Tag Syntax

<img src="image.jpg" alt="Description of image">

Key Attributes:

  • src - Source/path to the image file
  • alt - Alternative text for accessibility
  • width - Width of the image in pixels
  • height - Height of the image in pixels

Live Examples:

Best Practices:
  • Always include descriptive alt text for accessibility
  • Use appropriate image formats (JPG, PNG, WebP)
  • Optimize image sizes for web (reduce file size)
  • Provide relative paths for local images

Task 2: Embedding Audio

Learn how to embed audio files using the <audio> tag.

Audio Tag Syntax

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  the browser does not support the audio element.
</audio>

Key Attributes:

  • controls - Shows play, pause, volume controls
  • autoplay - Automatically plays when page loads
  • loop - Repeats the audio when it finishes
  • muted - Audio starts muted

Supported Formats:

  • MP3 (audio/mpeg)
  • WAV (audio/wav)
  • OGG (audio/ogg)
Key Concepts:
  • Always provide fallback text for older browsers
  • Use <source> tags for multiple formats (browser compatibility)
  • Audio files should be reasonably sized for web use
  • Avoid autoplaying audio (respect user experience)

Task 3: Embedding Video

Learn how to embed video files using the <video> tag.

Video Tag Syntax

<video width="320" height="240" controls>
  <source src="video.mp4" type="video/mp4">
  The browser does not support the video tag.
</video>

Key Attributes:

  • controls - Shows play, pause, timeline controls
  • width - Video player width
  • height - Video player height
  • poster - Image shown before video plays
  • autoplay - Automatically plays on page load
  • loop - Repeats video when finished

Live Example - Try the Video Player:

Sample Video

Supported Formats:

  • MP4 (video/mp4) - Most common
  • WebM (video/webm)
  • OGG (video/ogg)
Best Practices:
  • Always include width and height attributes
  • Use multiple <source> tags for browser compatibility
  • Add a poster image for better UX
  • Provide fallback content for unsupported browsers

Task 4: Embedding External Content (iframe)

Learn how to embed external web pages and videos using <iframe>.

IFrame Tag Syntax

<iframe width="560" height="315" src="https://www.youtube.com/embed/4UPKe2tKz54"
  title="YouTube video player" frameborder="0" allowfullscreen>
</iframe>

Key Attributes:

  • src - URL of the page to embed
  • width - Width of the iframe
  • height - Height of the iframe
  • frameborder - Shows/hides border (0 = no border)
  • allowfullscreen - Allows fullscreen mode
  • title - Accessibility title

Common Uses:

  • Embedding YouTube videos
  • Embedding Google Maps
  • Embedding external web pages
  • Embedding interactive content
  • Embedding tweets or social media
Security Considerations:
  • Only embed content from trusted sources
  • Use sandbox attribute to restrict permissions
  • Always include accessibility attributes like title
  • Test embedded content across different browsers

Learning Syntax Summary

📷 Images

Use <img> with src and alt attributes for responsive, accessible images.

🔊 Audio

Use <audio> with controls and source tags for embedded sound.

🎬 Video

Use <video> with width/height and source tags for embedded video.

🔗 Embedding

Use <iframe> to embed external content like YouTube or Maps.
